# Diagramas C4 y UML

Estos diagramas se deben cerrar después de probar la implementación. Los archivos fuente Mermaid se pueden abrir en un editor compatible o convertir a imagen para el informe.

- `c1-contexto.mmd`: personas y sistema de software.
- `c2-contenedores.mmd`: navegador, aplicación Java y almacenamiento JSON.
- `c3-componentes.mmd`: componentes reales dentro de la aplicación Java.
- `uml-clases.mmd`: clases, atributos, métodos y relaciones de implementación.

El nivel 3 de C4 muestra componentes; UML se usa para mostrar detalle de clases y métodos.
